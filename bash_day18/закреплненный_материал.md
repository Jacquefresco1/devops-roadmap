# Day 18 — Bash Arrays

## 1. Array

```bash
files=("app.sh" "config.conf" "server.log")
```

Массив хранит несколько значений под одним именем.

Индексация начинается с `0`.

---

## 2. Один элемент

```bash
echo "${files[0]}"
```

Для элемента массива нужны фигурные скобки:

```bash
${files[index]}
```

Не:

```bash
$files[0]
```

---

## 3. Все элементы

```bash
"${files[@]}"
```

---

## 4. Количество элементов

```bash
${#files[@]}
```

---

## 5. Перебор массива

```bash
for file in "${files[@]}"; do
    echo "$file"
done
```

---

## 6. Изменение

```bash
files[1]="nginx.conf"
```

---

## 7. Добавление

```bash
files+=("backup.sh")
```

---

## 8. Удаление

```bash
unset 'files[1]'
```

Удаление элемента не перенумеровывает остальные индексы.

---

## 9. Проверка существования

```bash
[[ -v 'files[1]' ]]
```

`-v` → существует ли элемент.

---

## 10. Фильтрация

```bash
shell_files=()

for file in "${files[@]}"; do
    if [[ "$file" == *.sh ]]; then
        shell_files+=("$file")
    fi
done
```

---

## 11. Передача элемента функции

```bash
show_file "$file"
```

Внутри функции:

```bash
$1
```

---

## 12. Передача всего массива функции

```bash
show_files "${files[@]}"
```

Внутри функции все полученные аргументы:

```bash
"$@"
```

Например:

```bash
show_files() {
    for file in "$@"; do
        echo "$file"
    done
}
```

---

## Главная связка Day 18

```text
"${files[@]}"
        ↓
элементы массива
        ↓
аргументы функции
        ↓
"$@"
        ↓
for
        ↓
обработка элементов
```

### Главная мысль

**Массив хранит список.
`for` перебирает список.
Функция позволяет вынести логику обработки.
`"${array[@]}"` передаёт элементы массива.
`"$@"` принимает все переданные аргументы внутри функции.**
