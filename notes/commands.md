## Навигация
pwd - показывает текущее местоположение(папка в которой находишься).

ls - показывает что в текущей папке(можно использовать с доп командами).

la - -l подробный список: права, владелец, размер, дата...| -a показать все, включая скрытые файлы и папки.

cd - перемещает между папкамка(в данном случае в корневую папку).

cd .. - на одну ступень назад.

cd- - команда перебрасывает межну двумя пунктами, что бы каждый раз не писать полный путь, если нужно быстро вернутся обратно. Между тем куда ты перешел и там где был до этого.

cd+(путь):cd devops/devops-roadmap/notes-(перемещает в указаную папку, если пусть полный, попадаешь с любого места куда указал, если конкретное название папки, ищет там где ты 
находишься).

cp - копирует файлы(содержимое) в конкретной папке.

mv - переместить или переименовать файл.

rm - удалить файл. rm -r удалить папку ивсе что в ней.

rmdir - удалить пустую папку.

find - поиск конкретного файла/папки.

grep - искать текст внутри файлов.

file - определить тип файла.

less - смотерть длинный текст.

head - показать начало файла.

tail - показать конец файла.

touch:touch commands.md - создает файл в указаной папке, можно применить принцип с cd(можно указать полный путь, если находишься в другой папке, тогда файл создаст непосредственно 
там).

mkdir:mrdir notes - создает папку в указано месте, так же можно указывать полный путь, тогда попка будет там, где хочешь, что бы она была.

cat:cat commands.md - показывает содержимое файла, так же можно вывести любой файл, указав его полный путь.

whoami - показать текущего пользователя.

cler - очистить историю.

history - показать историю команд.

nano:nano commands.md - открывает файл для внесения изменений, такой же принцип, можно указывать полный путь, если не находишься в папке с нужным файлом.

~ - символ для удобства, сокращает написание полного пути. Пример: команда+ /home/user/папка = ~/папка.
## Git

git status - показывает информацию после изменений файлов.

git add "название файла" - добавляет изменение или новый файл в standing.

git add . - добавляет всю текущую директорию со всеми файлами и другими поддиркториями в ней в standing.

git commit -m "Название того что сделал" - все что добавил в add сохраняется в историю git(commit).

git branch -d "название ветки" - удаляет локальную ветку, не удалит если есть незамерженные изменения.

git branch -D "название ветки" - удаляет без вопросов.

git merge "назвение ветки" - обьеденяет указную ветку в текущую, то есть важно где находишься, когда это делаешь.

git log --oneline - показывает историю commit, а именно то что было в скобочках.

git diff - показывает изменения в файлах, которые еще не добавлены в standing(git add)..

git diff --staged - показывает тоже самое что и просто git diff, но после команды git add(когда файл добавлен в standing).

git diff --cached - тоже самое, можно использовать или то или то.

git restore "название файла без скобочек" - отменяет изменение в файле, до того момента который был добавлен последним в standing.

git restore --staged "название файла" - убирает изменение которое было добавлено в git add(standing), но не убирает само изменение с файла.

git restore --source "название ветки" -- . - восстанавливает в данной ветке содержимое с указаной ветки(переносит).

git reset --soft HEAD~1 - убирает изменение в текущем commit, но оставляет изменения в standig и в самом файле ~1(указывает на сколько коммитов мы возвращае>

git reset --mixed HEAD~1 - убирает изменение в текущем commit так же убирает изменения с standing, оставляя их только в самом файле.

git reset --hard HEAD~1 - сносит все изменения до предыдущего commit.

git branch - показывает локальные ветки. * - значек возле ветки в которой находишься.

git branch "название без скобочек" - создает ветку с указаным названием, но не переключает на нее.

git branch -m "название без скобочек" - переименовывает ветку в которой находишься.

git switch "название" - переключает на указаную ветку

git switch -c "название" - создает новут ветку и сразу переключает на нее.

git push -u origin "название ветки без скобочек" - создает на github эту ветку, привязывает ее локальную версию на пк к ветке на github. Дальше достаточно просто git push находясь 
в этой ветке.

git push origin --delete "название ветки" - удаляет ветку с github.

git rm "название файла без скобочек" - удаляет файл и сообщает об это git. Как git add, только наоборот.

git rm -r "название папки" - удаляет папку и все содержимое, если вместо названия указать "." удалит текущую папку и ее содержимое.

git remote -v - показывает удаленные репозитории. Origin - обычно имя github-репозитория.

git push - отправляет локальные коммиты на github.

git log --oneline --graph --all --decorate - показывает общую историю коммитов всех веток.(oneline - один комит в одну строку; graph - визуальные линии ветвления; all - истории всех веток, не только текущей; decorate - показывает HEAD, название веток и другие указатели).

git reflog - история перемещений HEAD, есть показывает доп инфу, если сравнить с log.

git clone "ссылка с гитхаб на url" - создает клон репозитории в отдельную папку или же, если ты вытягиваешь с нуля, то получаешь все зодержимое для работы.

git fetch - показывает изменения в оригинальной версии на гидхаб.

git diff "ветка1" "ветка2" - показывает различие между двумя ветками(между клоном и оригиналом) или между двумя любыми.

git pull - добавляет изменения с гит хаб в клон(текущую ветку).

git pull "remote" "ветка1" - (git pull origin Linux) бучили в клоне, ты можешь вытянуть данные с конкретной ветки, не обязательно с той которую скопировал изначально.

git log "ветка1" "ветка2" - показывает коммиты, которые которые есть в одной ветке, но отсутвуют в другой.
