# Day 16 — Закреплённый материал

## 1. `shift`

Если первый аргумент имеет отдельное назначение:

```bash
directory="$1"
shift
```

то после `shift`:

```text
"$@" → все остальные аргументы
```

Используется, когда:

```text
$1 = directory
$2... = patterns
```

---

## 2. `for ... in "$@"`

Обрабатывает каждый аргумент отдельно:

```bash
for pattern in "$@"; do
    ...
done
```

`pattern` — текущий аргумент.

---

## 3. Функция + цикл

Для каждого аргумента можно вызвать одну и ту же функцию:

```bash
for pattern in "$@"; do
    check_files "$directory" "$pattern"
    status=$?
done
```

Функция получает:

```text
$1 → directory
$2 → pattern
```

---

## 4. Данные и статус

Функция может возвращать две разные вещи.

### Данные

```bash
files=$(find ...)
```

### Статус

```bash
return 0
return 1
return 2
```

Получение статуса:

```bash
status=$?
```

Главное правило:

```text
переменная → данные
return / $? → статус
```

---

## 5. `case`

Используется для выбора действия по значению:

```bash
case "$pattern" in
    *.sh)
        ...
    ;;
    *.conf)
        ...
    ;;
    *.log)
        ...
    ;;
    *)
        ...
    ;;
esac
```

`*` в последней ветке означает вариант по умолчанию.

---

## 6. `status` vs `overall_status`

```text
status
```

→ результат **текущей проверки**.

```text
overall_status
```

→ результат **всех проверок вместе**.

Начинаем:

```bash
overall_status=0
```

Приоритет:

```text
2 > 1 > 0
```

То есть:

```text
ERROR имеет приоритет над ATTENTION,
ATTENTION имеет приоритет над OK.
```

---

## 7. Полная схема

```text
$1 → directory
        ↓
     shift
        ↓
"$@" → patterns
        ↓
      for
        ↓
     pattern
        ↓
     function
        ↓
  files + status
        ↓
      case
        ↓
  обработка pattern
        ↓
 overall_status
        ↓
 System result
```

### Главная идея Day 16

**Один скрипт может принять одну директорию и сколько угодно patterns, пройти по ним циклом, передать каждый pattern в универсальную функцию, обработать результат через `status`, классифицировать pattern через `case` и в конце вывести единый `overall_status`.**
