# Bash Regex + grep -E — Закрепить

## 1. grep -E

```bash
grep -E "regex" file
```

Используется для поиска строк по Extended Regex.

---

## 2. Главные Regex

```text
.          → любой один символ
*          → 0+ повторений предыдущего элемента
+          → 1+ повторений предыдущего элемента
?          → 0 или 1 повторение
^          → начало строки
$          → конец строки
[abc]      → один символ: a, b или c
[0-9]      → одна цифра
[a-z]      → одна маленькая английская буква
[A-Z]      → одна большая английская буква
[a-zA-Z]   → одна английская буква
|          → OR
(...)      → группа
{2,4}      → от 2 до 4 повторений
```

---

## 3. Самые важные различия

### `.*`

```text
0+ любых символов
```

### `[a-zA-Z]+`

```text
1+ английских букв
```

### `[0-9]+`

```text
1+ цифр
```

---

## 4. Начало и конец строки

```text
^ERROR
```

→ строка начинается с `ERROR`.

```text
200$
```

→ строка заканчивается на `200`.

`$` всегда относится к **концу всей строки**.

---

## 5. OR

```text
(POST|GET)
```

→ POST или GET.

Без группировки:

```text
POST|GET$
```

не означает «POST или GET в конце».

Это означает:

```text
POST
```

или

```text
GET в конце строки
```

---

## 6. Regex и glob — не одно и то же

Glob:

```text
*.sh
```

→ любое имя, заканчивающееся на `.sh`.

Regex:

```text
.*\.sh
```

→ любое количество любых символов + `.sh`.

В Regex `*` повторяет предыдущий элемент.

---

## 7. Пример с access.log

```bash
grep -E "200$" access.log
```

→ строки, заканчивающиеся на `200`.

```bash
grep -E "5[0-9]{2}$" access.log
```

→ строки с кодом `500–599` в конце.

```bash
grep -E "^192\.168" access.log
```

→ строки, начинающиеся с `192.168`.

```bash
grep -E "/api/[a-zA-Z]+" access.log
```

→ `/api/` + одна или больше английских букв.

---

## 8. Важная мысль

Regex проверяет **структуру текста**, а не обязательно смысл.

Например:

```text
999.999.999.999
```

может соответствовать regex вида:

```text
[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}
```

потому что regex проверяет форму:

```text
числа.числа.числа.числа
```

но не знает, что настоящий IPv4-адрес ограничивает каждый октет значением `0–255`.

---

## Ключевая цепочка

```text
grep -E
   ↓
Regex
   ↓
определяем структуру совпадения
   ↓
^ / $ → позиция
[] → допустимые символы
+ / * → количество повторений
| → альтернативы
```

Главное сейчас — научиться **читать regex слева направо**, понимая, к какому именно элементу относится каждый оператор.
