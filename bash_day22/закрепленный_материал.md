## awk — базовая модель
- $1, $2... — поля строки (разделитель по умолчанию — пробел); $0 — вся строка целиком
- $1 в awk ≠ $1 в bash-скрипте (там это первый аргумент, тут — первое поле)
- -F 'разделитель' — задать свой разделитель полей (=, "," и т.д.)
- Структура: условие { действие } — выполняется на КАЖДОЙ строке файла автоматически (не нужен свой цикл)
- == для сравнения (не =, как в bash [ ])
- $NF — последнее поле, независимо от их количества (не NF — это просто число полей)
- NR — номер текущей строки, NF — количество полей в текущей строке
- ~ / !~ — оператор "соответствует / не соответствует regex", справа обязательно /паттерн/ (слэши — синтаксис awk, не bash-кавычки)
- ! — отрицание условия (та же логика, что -v в grep)

## Накопление и END
- sum += $2 — накопить значение между строками (переменная стартует с 0 автоматически)
- count++ — счётчик без арифметики над значением
- END { ... } — единственный блок БЕЗ условия, выполняется один раз, после того как весь файл прочитан
- без END — print сработал бы на каждой строке с промежуточным значением, а не итогом

## Обработка ошибок в bash
- set -e — скрипт останавливается при первой команде с ненулевым exit-кодом
- set -u — ошибка при обращении к необъявленной переменной (без флага — молча подставляется пустая строка)
- set -o pipefail — ошибка в СЕРЕДИНЕ pipe тоже считается ошибкой (по умолчанию учитывается только последняя команда цепочки)
- set -euo pipefail — стандартная строгая шапка, ставится ПЕРВОЙ строкой после shebang (не в середине скрипта — иначе не защищает то, что было до неё)
- порядок букв в -euo не важен, КРОМЕ случая когда -o не последняя буква в связке (у -o есть отдельный аргумент — pipefail)

## trap
- trap 'команда' EXIT — выполняет команду при ЛЮБОМ завершении скрипта (успех, ошибка, Ctrl+C, kill)
- EXIT — псевдо-сигнал bash, не настоящий Unix-сигнал (в отличие от INT, TERM)
- команда в trap — в одинарных кавычках (выполняется позже, при срабатывании, не в момент объявления)
- trap должен быть объявлен ДО того, как сигнал может произойти — если Ctrl+C нажат до строки с trap, обработчик ещё не зарегистрирован и не сработает
- практическая польза vs "команда последней строкой": trap срабатывает даже если скрипт оборвался ДО конца (ошибка, Ctrl+C) — обычная команда в конце файла в этом случае просто не будет достигнута
