Задача 1.
1.Создал файл
2. Команды для проверки
-git видит файл
-какие именно изменения в working tree.

решение:
git status - увидим общее изменение. Что бы узнать что именно добавилось в этом файле, нужно добавить его в standing. Так как файл новый на данной ветке, git diff ничего не даст и только после коммита, можно вывести информацию git --staged. Если же мы внесем еще одно озменение в этот файл, тогда git diff уже покажет его, так как будет иметь локальную версию для сравнения.
