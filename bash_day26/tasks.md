1. Скрипт с одним аргументом — путь к файлу. Если файла нет, ошибка и выход. Если есть: вывести его права в числовом виде (не ls -l как есть, а именно переведённое число вроде 644) и отдельно — владельца и группу. Подумай, какая команда умеет выводить права сразу в восьмеричном формате, без ручного перевода (подсказка: не ls, есть отдельная команда для этого, можешь поискать сам, если не помнишь — это нормально, учиться гуглить нужные флаги тоже часть навыка).
2. На access.log: через awk посчитай отдельно количество GET, POST, DELETE одним проходом по файлу (три разных счётчика в одном скрипте awk, не три отдельных запуска).
3. Собери pipe из трёх команд: найди все .sh-файлы в текущей папке, вытащи из каждого первую строку (shebang), и посчитай, сколько из них начинаются именно с #!/bin/bash, а не с чего-то другого.
4. Скрипт, который принимает имя пользователя и создаёт его, только если он состоит в графе "уже решённая проблема": то есть сначала проверка, если уже существует — не падать с ошибкой, а просто сообщить "уже есть" и продолжить выполнение дальше по скрипту (не exit), добавив его в группу users на всякий случай.
5. Без скрипта, одной командой: узнай, сколько процессов сейчас запущено в системе всего (не только твоих), используя ps aux и подсчёт строк, с поправкой на то, что первая строка — заголовки таблиц, её считать не нужно.
