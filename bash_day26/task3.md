1. омбинация grep -c + $(( )). Скрипт с одним аргументом (файл), с проверкой существования. Выведи общее число строк, число пустых строк и сколько строк непустых. Пустая строка в regex это ^$ (начало сразу за которым конец).
2. Новое: массив в awk. В bash ты уже работал с ассоциативными массивами (declare -A). В awk они есть без объявления: count[$1]++ значит «увеличь счётчик под ключом $1», а в END цикл for (ip in count) { print ip, count[ip] } проходит по всем ключам. Задача: на access.log выведи для каждого IP, сколько запросов с него пришло. Строку INVALID LINE... отфильтруй условием перед счётчиком (подумай, по какому полю или признаку её отличить).
3. Комбинация -F + условие + wc -l. Без скрипта, одной командой на /etc/passwd: выведи имена пользователей, у которых оболочка /bin/bash. Затем посчитай, сколько их. Разделитель полей в этом файле :, а оболочка в последнем поле.
4. Комбинация ss + grep + if. Скрипт без аргументов: проверь, слушается ли порт 22 (ss -tuln), и выведи Port 22 is open или Port 22 is closed. Решение должно опираться на код возврата grep, а не на подсчёт или сравнение текста. Вспомни &>/dev/null из проверки пользователя.
5. Комбинация stat + if + -eq. Скрипт с одним аргументом (файл). Через stat -c "%a" получи числовые права. Если это 777, выведи предупреждение, что права слишком открыты. Иначе выведи OK: права <число>.
