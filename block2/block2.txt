##Block2
Restore
Дефолтный рестор проверили, сейчас протестим git restore --staged и достаем его со standing.

Если мы добавим файл в commit, а затем сделаем git rm "этот файл". Можно его восстановить не меняя историю. То есть мы можем сделать:
1. git restore --staged "file"
2. git restore "file" 
И вернуть его туде где он был
