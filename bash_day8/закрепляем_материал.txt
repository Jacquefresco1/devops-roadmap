DAY 8 — Закрепляем материал

1. $? относится к последней выполненной команде.

Если после нужной команды выполнить другую команду, $? уже будет содержать status этой новой команды.

Поэтому:
ls /this-does-not-exist 
echo "Hello" 
echo $?
покажет status echo, а не ls.

2. exit без аргумента не означает exit 0.

exit
использует exit status последней выполненной команды.

Например:
ls /this-does-not-exist 
exit
Если ls вернул 2, весь скрипт завершится с status 2.

3. Ненулевой exit status не обязательно равен 1.

Например:
ls /this-does-not-exist
→ exit status 2.
Для условной логики:
0 → успех 
не 0 → ошибка.

4. Exit status и false — не одно и то же.

2 — это числовой exit status.
Он становится false в условии, например:
[ $? -eq 0 ]
Если $? = 2:
[ 2 -eq 0 ]
→ false.

5. if может проверять команду непосредственно.

Вместо:
ls /tmp 
if [ $? -eq 0 ]; then 
	... 
fi

можно:

if ls /tmp; then 
	... 
fi
Так мы проверяем результат команды непосредственно и не рискуем потерять нужный $?.

6. case не перебирает ветки после совпадения.

Если $1 = stop, Bash находит:
stop)
и выполняет эту ветку.
Он не возвращается потом к start).

7. ;; и exit имеют разный смысл.

;; → закончить текущую ветку case. 
exit → немедленно завершить весь скрипт.
Если после case есть код:
case "$1" in 
	start) 
	echo "Starting" 
	;; 
esac
echo "Next command"

то echo "Next command" выполнится.

Если вместо ;; использовать exit:
case "$1" in 
	start) 
	echo "Starting" 
	exit 0 
	;; 
esac
echo "Next command"

то до echo "Next command" выполнение не дойдёт.

8. A && B || C не всегда равно if/else.

Пример:
A && B || C
если A успешна → выполняется B.
Но если B сама завершится с ошибкой → выполнится C.
Поэтому для простой логики конструкция удобна, а для сложной логики безопаснее обычный if/else.

9. && и || можно использовать вместе с проверками.

[ -d backup ] && echo "Backup exists" || echo "Backup does not exist"

Если backup существует: 
[ -d backup ] → 0 
→ запускается первое echo.

Если backup не существует: 
[ -d backup ] → ненулевой status 
→ первое echo не запускается 
→ запускается второе echo.
