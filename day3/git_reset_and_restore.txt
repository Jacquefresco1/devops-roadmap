git restore "название файта" - убирает изменения в файле, до момента, когда он был добавлен в standing(git add). Возвращает его к последнй версии standing.

git restore --staged "название файла" - убирает изменение файла из standing, но не меняет ничего внутри самого файла.

git reset --soft HEAD~1 - убирает изменение в текущем commit, но оставляет изменения в standig и в самом файле ~1(указывает на сколько коммитов мы возвращается назад, HEAD это текущий коммит ~1,2,3 откатывает на 1 2 или 3 commit назад.

git reset --mixed HEAD~1 - убирает изменение в текущем commit так же убирает изменения с standing, оставляя их только в самом файле.

git reset --hard HEAD~1 - сносит все изменения до предыдущего commit.
