# Day 19 — Associative Arrays

## Главное

Associative array:

```bash
declare -A types
```

хранит данные как:

```text
key → value
```

Например:

```bash
types["*.sh"]="Shell"
types["*.conf"]="Config"
types["*.log"]="Logs"
```

---

## Базовые операции

Получить значение:

```bash
echo "${types["*.sh"]}"
```

Получить все значения:

```bash
echo "${types[@]}"
```

Получить все ключи:

```bash
echo "${!types[@]}"
```

Пройти по ключам:

```bash
for pattern in "${!types[@]}"; do
    echo "$pattern -> ${types[$pattern]}"
done
```

---

## Динамический ключ

Если:

```bash
pattern="*.sh"
```

то:

```bash
${types[$pattern]}
```

означает:

```text
$pattern
↓
"*.sh"
↓
types["*.sh"]
↓
Shell
```

Это позволяет использовать переменную как ключ.

---

## Критически важное различие

`case` и associative array работают с `*` по-разному.

В `case`:

```bash
case "$file" in
    *.sh)
        ...
    ;;
esac
```

`*.sh` → **pattern matching**.

В associative array:

```bash
types["*.sh"]="Shell"
```

`*.sh` → **буквальный key**.

Поэтому:

```text
case → pattern matching
array → exact key lookup
```

---

## Архитектура

Associative array особенно полезен как mapping:

```text
key → value
```

Например:

```text
*.sh   → Shell
*.conf → Config
*.log  → Log
```

А обычный массив может содержать входные данные:

```text
*.sh
*.conf
*.log
```

После чего:

```text
обычный array
      ↓
    $pattern
      ↓
associative array
      ↓
   value
```

Главная мысль Day 19:

> **Associative array — это не «массив с номерами», а способ хранить и получать данные через осмысленный ключ.**
